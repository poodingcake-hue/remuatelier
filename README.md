# 리뮤아틀리에 브랜드 사이트 (MVP)

아이가 입던 옷으로 담요·가방을 만드는 리뮤아틀리에의 자체 브랜드 사이트입니다.
결제와 리뷰는 네이버 스마트스토어를 그대로 쓰고, 이 사이트는 이야기·체험·예약 안내를 맡습니다.

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

Node 20 이상, Next.js 15 · React 19 · three.js(@react-three/fiber, drei).
TypeScript는 5.x로 고정되어 있어요 (Next 15가 TS 7을 아직 읽지 못함).

## 페이지

| 경로 | 내용 |
| --- | --- |
| `/` | 패치 담요가 꿰매어지는 첫 화면, 다음 예약 오픈, 옷장 편지, 옷 개수별 작품 |
| `/about` | 브랜드 이야기와 네 가지 가치 |
| `/collection` | 작품 목록 + 옷 개수 계산기 |
| `/stories` | 옷장 편지 (고객 사연 아카이브) |
| `/studio` | 미리 만들어 보기: 담요 2D 배치 / 가방 3D 패치 붙이기 |
| `/how` | 맡기는 과정 5단계 + FAQ |
| `/reserve` | 오픈 알림 신청, 작업 일지 조회(데모 번호 `REMU-0001`), 사연 보내기 |
